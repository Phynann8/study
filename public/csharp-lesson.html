C# Tutorial

C# (C-Sharp) is a programming language developed by Microsoft that runs on the .NET Framework.

This page is dedicated to C# lessons. Below are some example modules you might include in a learning path:

Module 1: CS Fundamentals (មូលដ្ឋានគ្រឹះ)

4 Units • Khmer Localized

សិក្សាអំពីមូលដ្ឋានគ្រឹះនៃការសរសេរកូដដោយប្រើឧទាហរណ៍ជាក់ស្តែង។

Overview ▼

  • មេរៀនទី ១: អថេរ (Variables)
  • មេរៀនទី ២: Loops (ការធ្វើឡើងវិញ)
  • មេរៀនទី ៣: តក្កវិជ្ជា (Logic)
  • មេរៀនទី ៤: អង្គចងចាំ (Memory Management)

Module 2: OOP (ការរៀបចំប្រព័ន្ធ)

3 Units • Khmer Localized

រៀនអំពីការរៀបចំកូដឱ្យមានរបៀបរៀបរយដូចការគ្រប់គ្រងហាងពិតប្រាកដ។

Overview ▼

  • ២.១ Classes & Objects (ប្លង់មេ)
  • ២.២ Inheritance (មរតកបន្តវេន)
  • ២.៣ Polymorphism (ភាពច្រើនបែប)
  • ២.៤ គម្រោង៖ ប្រព័ន្ធគ្រប់គ្រងហាង (POS)

Module 3: Modern C# & .NET (បច្ចេកវិទ្យាទំនើប)

4 Units • Khmer Localized

សិក្សាអំពីការប្រើប្រាស់ LINQ, Async/Await និងការគ្រប់គ្រងទិន្នន័យ។

Overview ▼

  • ៣.១ LINQ (ការចម្រាញ់ទិន្នន័យ)
  • ៣.២ Async/Await (ការងារច្រើនក្នុងពេលតែមួយ)
  • ៣.៣ SQL & Data (ការរក្សាទុកទិន្នន័យ)
  • ៣.៤ គម្រោង៖ ប្រព័ន្ធគ្រប់គ្រងនិស្សិត
