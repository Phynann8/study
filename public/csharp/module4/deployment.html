មេរៀនទី ៤.៣៖ Deployment (ការបើកហាង) 🚀

Deployment គឺជាការយកកូដពីក្នុងម៉ាស៊ីនរបស់យើង (Localhost) ទៅដាក់នៅលើអ៊ីនធឺណិត (Server) ដើម្បីឱ្យមនុស្សទូទាំងពិភពលោកប្រើប្រាស់បាន។

🏗️ ឧទាហរណ៍៖ ពីផ្ទះបាយទៅហាងពិត

នៅពេលអ្នករៀនធ្វើម្ហូប អ្នកធ្វើនៅផ្ទះខ្លួនឯង (Localhost) ញ៉ាំតែម្នាក់ឯង។ ប៉ុន្តែពេលអ្នកចង់លក់ អ្នកត្រូវជួលទីតាំង (Server) និងរៀបចំតុ (IIS/Docker) ដើម្បីទទួលភ្ញៀវ។

🏠 Localhost

កុំព្យូទ័រផ្ទាល់ខ្លួន

មានតែយើងទេដែលឃើញ
➡️

☁️ Server (IIS/Linux)

កុំព្យូទ័រដែលបើក ២៤ម៉ោង

មនុស្សគ្រប់គ្នាអាចចូលបាន

🛠️ ឧបករណ៍សំខាន់ៗ៖

  • IIS (Internet Information Services): ជាអ្នកគ្រប់គ្រងហាងនៅលើ Windows Server។
  • Docker 🐳: ជា "ប្រអប់អាហារ" ដែលវេចខ្ចប់កូដរបស់យើងឱ្យយកទៅដាក់នៅទីណាក៏បាន។
  • Domain Name (eg. khmercode.com): គឺជា "អាសយដ្ឋានហាង" ដើម្បីឱ្យភ្ញៀវរកឃើញ។

📝 សាកល្បងចំណេះដឹង (Quiz)

តើកម្មវិធីអ្វីដែលគេនិយមប្រើសម្រាប់ "វេចខ្ចប់" (Containerize) កម្មវិធីឱ្យងាយស្រួលចល័ត?
