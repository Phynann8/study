មេរៀនទី ៤.១៖ ASP.NET Core (រចនាសម្ព័ន្ធហាងបាយ) 🍲

ASP.NET Core គឺជា Framework របស់ Microsoft សម្រាប់បង្កើត Website ទំនើបៗ។ ដើម្បីងាយយល់ យើងនឹងប្រៀបធៀបវាទៅនឹង "ហាងបាយ" មួយ។

🏠 ឧទាហរណ៍៖ ដំណើរការក្នុងហាងបាយ

នៅពេលភ្ញៀវ (User) កម្ម៉ង់ម្ហូប វាមានដំណាក់កាលដូចខាងក្រោម៖

👤

Client (ភ្ញៀវ)

អ្នកដែលចូលមកមើល Website (Browser)

➡️
🤵

Controller (អ្នករត់តុ)

អ្នកទទួលការកម្ម៉ង់ និងចាត់ចែង (C# Code)

➡️
👨‍🍳

Model/Service (ចុងភៅ)

អ្នកធ្វើម្ហូប និងចាត់ចែងទិន្នន័យ (Logic & Data)

➡️
🍲

View (ម្ហូប)

អ្វីដែលភ្ញៀវទទួលបាន (HTML Page)

🔍 ពាក្យគន្លឹះ (MVC Pattern)៖

  • Model: តំណាងឱ្យទិន្នន័យ (ឧទាហរណ៍៖ មុខម្ហូប, តម្លៃ)។
  • View: ផ្នែកដែលបង្ហាញឱ្យគេឃើញ (HTML/CSS)។
  • Controller: អ្នកសម្របសម្រួលរវាង Model និង View។

📝 សាកល្បងចំណេះដឹង (Quiz)

នៅក្នុង MVC, តើផ្នែកណាដែលមានតួនាទីដូច "អ្នករត់តុ"?
