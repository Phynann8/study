មេរៀនទី ៤.២៖ API & REST (អ្នករត់តុ) 🤵

API (Application Programming Interface) គឺជាវិធីដែលកម្មវិធីពីរអាចនិយាយរកគ្នាបាន។ បើប្រៀបធៀបនឹងហាងបាយ API គឺជា "អ្នករត់តុ"។

🤵 ឧទាហរណ៍៖ ការកុម្ម៉ង់អាហារ

ភ្ញៀវមិនអាចដើរចូលទៅចម្អិនម្ហូបក្នុងផ្ទះបាយដោយខ្លួនឯងទេ (Database)។ ភ្ញៀវត្រូវប្រាប់អ្នករត់តុ (API) ថាចង់ញ៉ាំអី ហើយអ្នករត់តនឹងយកសំណើទៅប្រាប់ចុងភៅ រួចយកម្ហូបមកឱ្យភ្ញៀវវិញ។

💻 RESTful Methods (កាយវិការកុម្ម៉ង់)

  • GET 📖: សុំមើលមឺនុយ ឬទិន្នន័យ (ដូចពេលសុំមើល Menu)។
  • POST 📝: កុម្ម៉ង់ម្ហូបថ្មី (ដូចពេលកុម្ម៉ង់បាយឆាមួយ)។
  • PUT 🔄: ដូរការកុម្ម៉ង់ (ដូចពេលសុំដូរបាយឆា យកបាយសាច់ជ្រូកវិញ)។
  • DELETE ❌: លុបការកុម្ម៉ង់ (ដូចពេលប្រាប់ថា "អត់យកវិញទេ")។

🔍 JSON (ភាសាសកល)

អ្នករត់តុ (API) និយាយភាសាមួយឈ្មោះថា JSON ដើម្បីឆ្លើយឆ្លងគ្នា។

{
  "food": "Bay Cha",
  "price": 2.50,
  "spicy": true
}
