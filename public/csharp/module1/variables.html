មេរៀនទី ១: អថេរ (Variables) - ប្រអប់ដាក់អីវ៉ាន់

ស្រមៃថាអ្នកកំពុងរៀបចំផ្ទះ។ អ្នកត្រូវការ "ប្រអប់" ដើម្បីដាក់របស់របរ។

  • ប្រអប់ដាក់តុក្កតា
  • ប្រអប់ដាក់សៀវភៅ
  • ប្រអប់ដាក់ស្បែកជើង

នៅក្នុងការសរសេរកូដ Variables (អថេរ) គឺដូចជា "ប្រអប់" សម្រាប់រក្សាទុកទិន្នន័យ។

របៀបបង្កើត "ប្រអប់" (Syntax)


int age = 20;
string name = "Sokha";

ការពន្យល់:

  • int (Integer): គឺជាប្រអប់សម្រាប់ដាក់ លេខ (ដូចជាអាយុ)។
  • string: គឺជាប្រអប់សម្រាប់ដាក់ អក្សរ (ដូចជាឈ្មោះ)។
  • =: គឺជារបៀបដែលយើងដាក់របស់ចូលក្នុងប្រអប់។
