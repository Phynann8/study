មេរៀនទី ២: Loops (ការធ្វើឡើងវិញ) - វដ្តជីវិតស្រែ

តើកសិករធ្វើអ្វីខ្លះជារៀងរាល់ឆ្នាំ? គាត់ធ្វើស្រែមានរដូវកាលច្បាស់លាស់៖

  1. ភ្ជួរស្រែ
  2. សាបព្រោះ
  3. ច្រូតកាត់
  4. (ធ្វើម្ដងទៀតនៅឆ្នាំក្រោយ)

នៅក្នុងកូដ កាលណាយើងចង់ធ្វើអ្វីមួយម្ដងទៀតច្រើនដង យើងប្រើ Loops ដើម្បីកុំឱ្យសរសេរកូដដដែលៗ ច្រើនដង។

For Loop (ការធ្វើឡើងវិញមានកំណត់)


for (int i = 0; i < 5; i++) 
{
    Console.WriteLine("ភ្ជួរស្រែលើកទី: " + i);
}

ការពន្យល់:

  • int i = 0: ចាប់ផ្តើមពី ០ ។
  • i < 5: ធ្វើរហូតដល់តិចជាង ៥ ដង (បានន័យថា ៥ ដង) ។
  • i++: រាល់ពេលធ្វើចប់ម្ដង រាប់ថែម ១ ។
