មេរៀនទី ៣: Delegates (អ្នកតំណាង)

Delegate គឺដូចជា "អ្នកតំណាង" ឬ "បេសកជន"។ វាគឺជា Variable ដែលអាចរក្សាទុក Function បាន។

ជំនួសឲ្យការហៅ Function ផ្ទាល់ យើងអាចហៅវាឆ្លងកាត់ Delegate។

របៀបប្រើប្រាស់ (Syntax)


// 1. បង្កើត Delegate
delegate void MyDelegate(string message);

// 2. បង្កើត Function ធម្មតា
void SayHello(string msg) 
{
    Console.WriteLine("Hello: " + msg);
}

// 3. ប្រើប្រាស់
MyDelegate del = SayHello; // ដាក់ Function ចូល Delegate
del("Sokha"); // លទ្ធផល: Hello: Sokha

អត្ថប្រយោជន៍:

  • អាចប្តូរ Function ដែលត្រូវដំណើរការនៅពេល Run កម្មវិធី។
  • ប្រើសម្រាប់បង្កើត Events (ដូចជាពេលចុច Button)។
  • ជួយឲ្យកូដមានភាពបត់បែន (Flexible)។

សាកល្បងគិតមើល!
