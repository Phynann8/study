មេរៀនទី ៤: Lambda Expressions (=>)

Lambda Expression គឺជាវិធីសរសេរ Function យ៉ាងខ្លីដោយប្រើសញ្ញា =>។

វាមានប្រយោជន៍ខ្លាំងពេលប្រើជាមួយ LINQ ឬពេលដែលយើងត្រូវការ Function តែមួយភ្លែត។

របៀបប្រើប្រាស់ (Syntax)


// របៀបសរសេរធម្មតា
int Square(int x) 
{
    return x * x;
}

// របៀបសរសេរ Lambda
(x) => x * x;

ឧទាហរណ៍ជាក់ស្តែងជាមួយ List:


List numbers = new List { 1, 2, 3, 4, 5 };

// ចង់បានតែលេខគូ (Even numbers)
var evens = numbers.Where(n => n % 2 == 0);

// បង្ហាញលទ្ធផល: 2, 4

ការពន្យល់:

  • n: តំណាងឲ្យលេខនីមួយៗក្នុងបញ្ជី។
  • =>: មានន័យថា "goes to" ឬ "ក្លាយជា"។
  • n % 2 == 0: លក្ខខណ្ឌ (Condition)។

សាកល្បងគិតមើល!
