មេរៀនទី ៥: Reflection (ឆ្លុះបញ្ចាំង)

Reflection គឺសមត្ថភាពរបស់កូដក្នុងការ "មើលខ្លួនឯង" នៅពេលកំពុងដំណើរការ។ វាអាចឲ្យយើងពិនិត្យមើល Class, Method, ឬ Property ដោយមិនចាំបាច់ស្គាល់វាមុន។

វាក៏អនុញ្ញាតឲ្យយើងប្រើ Attributes (ស្លាកសញ្ញា) ដើម្បីផ្តល់ព័ត៌មានបន្ថែមដល់កូដ។

ឧទាហរណ៍: ការប្រើ Attributes


// បង្កើតស្លាកសញ្ញាផ្ទាល់ខ្លួន
[Obsolete("កុំប្រើ Function នេះអី វាចាស់ហើយ!")]
public void OldMethod() 
{
    Console.WriteLine("Old Code");
}

// នៅពេលអ្នកហៅ OldMethod() កម្មវិធីនឹងព្រមានអ្នក។

ការប្រើប្រាស់ជាក់ស្តែង:

  • Testing Frameworks (ដូចជា NUnit, xUnit) ប្រើ Attribute [Test] ដើម្បីសម្គាល់ថា Function ណាជា Test។
  • Database (Entity Framework) ប្រើ [Key] ដើម្បីសម្គាល់ Primary Key។

សាកល្បងគិតមើល!
