មេរៀនទី ៦: Unit Testing (ការធ្វើតេស្ត)

Unit Testing គឺជាការសរសេរកូដ ដើម្បីតេស្តកូដរបស់អ្នកផ្សេងទៀត។ វាជួយធានាថាកម្មវិធីរបស់យើងដំណើរការត្រឹមត្រូវ និងមិនមានកំហុស (Bugs)។

នៅក្នុង C# យើងច្រើនប្រើ xUnit, NUnit, ឬ MSTest។

គោលការណ៍ AAA

រាល់ការតេស្តគួរតែមាន 3 ជំហាន:

  • Arrange: រៀបចំទិន្នន័យ (ដូចជាបង្កើត Variable)។
  • Act: ធ្វើសកម្មភាព (ហៅ Function ដែលចង់តេស្ត)។
  • Assert: ផ្ទៀងផ្ទាត់លទ្ធផល (តើលទ្ធផលត្រឹមត្រូវឬអត់?)។

ឧទាហរណ៍:


[Test]
public void TestAddition()
{
    // Arrange
    int a = 5;
    int b = 10;

    // Act
    int sum = a + b;

    // Assert
    Assert.AreEqual(15, sum);
}

សាកល្បងគិតមើល!
