មេរៀនទី ៣.៣៖ Data & SQL (បន្ទប់ផ្ទុកទិន្នន័យ) 🗄️

Database គឺជាកន្លែងសម្រាប់រក្សាទុកទិន្នន័យឱ្យមានរបៀបរៀបរយបំផុត ចំណែកឯ SQL គឺជាភាសាសម្រាប់បញ្ជាឱ្យ Computer ទាញទិន្នន័យទាំងនោះមកប្រើ។

🗄️ ឧទាហរណ៍៖ បន្ទប់ដាក់អីវ៉ាន់

ស្រមៃថាអ្នកមានបន្ទប់ដាក់អីវ៉ាន់មួយដែលមានធ្នើរ (Table) ច្រើន។ ធ្នើរនីមួយៗមានស្លាកឈ្មោះ (Columns) ហើយនៅលើធ្នើរមានរបស់របរ (Rows) ជាច្រើន។

💻 ភាសា SQL (CRUD)

-- ជ្រើសរើសនិស្សិតដែលមកពីភ្នំពេញ
SELECT * FROM Students 
WHERE City = 'Phnom Penh';

-- បន្ថែមនិស្សិតថ្មី
INSERT INTO Students (Name, Age) 
VALUES ('Sokha', 20);

🔍 ពាក្យគន្លឹះសំខាន់ៗ៖

  • Table: ដូចជាធ្នើរមួយប្រភេទ (ឧទាហរណ៍៖ ធ្នើរសម្រាប់សៀវភៅ ធ្នើរសម្រាប់សំលៀកបំពាក់)។
  • SELECT: ការ "ទាញយក" ឬ "បង្ហាញ" ទិន្នន័យ។
  • INSERT: ការ "បន្ថែម" ទិន្នន័យថ្មីចូល។
  • UPDATE: ការ "កែប្រែ" ទិន្នន័យចាស់។
  • DELETE: ការ "លុប" ទិន្នន័យចោល។

📝 សាកល្បងចំណេះដឹង (Quiz)

តើពាក្យ SQL មួយណាដែលយើងប្រើដើម្បី "កែប្រែ" ទិន្នន័យដែលមានស្រាប់?
