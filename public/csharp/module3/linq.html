មេរៀនទី ៣.១៖ LINQ (ការចម្រាញ់ផលស្រូវ) 🌾

LINQ (Language Integrated Query) គឺជាបច្ចេកវិទ្យាដ៏អស្ចារ្យក្នុង C# ដែលអនុញ្ញាតឱ្យយើង "សួរ" ឬ "ចម្រាញ់" ទិន្នន័យពីបញ្ជី (List/Array) បានយ៉ាងងាយស្រួល ដូចការរើសអង្ករល្អចេញពីអង្ករអន់អញ្ចឹង!

🌾 ឧទាហរណ៍៖ ការចម្រាញ់ផលស្រូវ

ស្រមៃថាអ្នកមានអង្ករច្រើនបាវ (List of Rice Bags)។ អ្នកចង់រកតែបាវណាដែលមានទម្ងន់លើសពី ៥០គីឡូ ហើយរៀបតាមលំដាប់ពីធ្ងន់ទៅស្រាល។

💻 កូដ LINQ (ស្ទីលទំនើប)

List<RiceBag> myHarvest = GetAllRice();

// ប្រើ LINQ ដើម្បីចម្រាញ់
var goodRice = myHarvest
    .Where(r => r.Weight > 50)      // រកតែបាវលើសពី ៥០គីឡូ
    .OrderByDescending(r => r.Weight) // រៀបពីធ្ងន់ទៅស្រាល
    .ToList();

🔍 ពាក្យគន្លឹះសំខាន់ៗ៖

  • .Where(): ដូចជាការ "រែង" (Filter) - យកតែអ្វីដែលត្រូវនឹងលក្ខខណ្ឌ។
  • .OrderBy(): ការ "រៀបជួរ" (Sort) - តាមលំដាប់លំដោយ។
  • .Select(): ការ "ជ្រើសរើស" - យកតែផ្នែកខ្លះនៃទិន្នន័យ (ឧទាហរណ៍ យកតែតម្លៃ មិនយកឈ្មោះបាវ)។
  • .FirstOrDefault(): យក "អ្នកលើគេបង្អស់" ឬ "ទទេ" បើរកមិនឃើញ។

📝 សាកល្បងចំណេះដឹង (Quiz)
