មេរៀនទី ៣.២៖ Async & Await (ចុងភៅឆ្លាតវៃ) 👨‍🍳

Asynchronous Programming គឺជាជំនាញដែលអនុញ្ញាតឱ្យកម្មវិធីរបស់យើងធ្វើការងារច្រើនក្នុងពេលតែមួយដោយមិនចាំបាច់ "បង្កក" ឬ "គាំង" (Non-blocking)។

🍳 ឧទាហរណ៍៖ ចុងភៅ និងការដាំទឹក

បើចុងភៅឈរចាំតែទឹកពុះ (Synchronous) ទើបទៅហាន់បន្លែ នោះគាត់នឹងចំណាយពេលយូរ។ ប៉ុន្តែបើគាត់ដាក់ដាំទឹក រួចទៅហាន់បន្លែបណ្តើរ (Asynchronous) គាត់នឹងរួចរាល់លឿនជាង!

💻 កូដ Async (ការងារមិនបង្កក)

public async Task MakeBreakfast() {
    // ដាក់ដាំទឹក (ចាប់ផ្តើមធ្វើការងារដែលយូរ)
    var boilingTask = BoilWaterAsync(); 

    // ហាន់បន្លែ (ធ្វើការងារផ្សេងបណ្តើរ)
    ChopVegetables();

    // ចាំទាល់តែទឹកពុះទើបបន្ត
    await boilingTask; 

    Console.WriteLine("ទឹកពុះហើយ! ឆ្អិនបាត់!");
}

🔍 ពាក្យគន្លឹះសំខាន់ៗ៖

  • async: ប្រាប់ថា Method នេះមានសមត្ថភាពធ្វើការងារ "មិនបង្កក"។
  • await: ប្រាប់ឱ្យកម្មវិធី "ចាំ" ទាល់តែការងារមួយរួចរាល់ ប៉ុន្តែកម្មវិធីផ្សេងៗនៅដើរធម្មតា។
  • Task: គឺជា "កិច្ចសន្យា" ថាការងារមួយនឹងរួចរាល់នៅថ្ងៃក្រោយ។
