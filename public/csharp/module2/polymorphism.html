មេរៀនទី ២.៣: Polymorphism - ភាពច្រើនបែបនៃឧបករណ៍

Polymorphism មកពីពាក្យក្រិចដែលមានន័យថា "ទម្រង់ច្រើន" ។

ស្រមៃថាអ្នកមានពាក្យបញ្ជាមួយថា "បង់ប្រាក់" ។ អ្នកអាចបង់ជា៖

  • លុយសុទ្ធ (Cash)
  • កាតធនាគារ (Card)
  • ស្កែន ABA (QR Code)

ទោះបីវិធីផ្សេងគ្នា ប៉ុន្តែគោលដៅគឺតែមួយគឺ "បង់ប្រាក់"។

១. របៀបប្រើក្នុងកូដ (Method Overriding)

យើងប្រើពាក្យ virtual សម្រាប់មេ និង override សម្រាប់កូន។


class Payment 
{
    public virtual void Pay() { Console.WriteLine("កំពុងចាត់ចែង..."); }
}

class AbaPayment : Payment 
{
    public override void Pay() { Console.WriteLine("បង់តាម ABA ជោគជ័យ!"); }
}
