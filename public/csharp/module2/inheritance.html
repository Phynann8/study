មេរៀនទី ២.២: Inheritance - មរតកបន្តវេនពីគ្រួសារ

ក្នុងជីវិតពិត យើងតែងតែទទួលបាន "មរតក (Inheritance)" ពីឪពុកម្តាយ ដូចជាកេរ្តិ៍ឈ្មោះ នាមត្រកូល ឬមុខរបរគ្រួសារ។

នៅក្នុងកូដ Inheritance អនុញ្ញាតឱ្យ Class ថ្មី យកលក្ខណៈសម្បត្តិពី Class ចាស់ ដោយមិនបាច់សរសេរឡើងវិញ។

១. Base Class (ឪពុកម្តាយ)

ស្រមៃថាអ្នកមាន Class មេឈ្មោះ Item ដែលមាន 'ឈ្មោះ' និង 'តម្លៃ'។


class Item 
{
    public string Name;
    public int Price;
}

២. Derived Class (កូន)

ឥឡូវអ្នកបង្កើត FoodItem ។ វាគឺអីវ៉ាន់ (Item) ដែរ ប៉ុន្តែវាមានថែម 'ថ្ងៃផុតកំណត់' (Expiry)។ 


class FoodItem : Item // : មានន័យថា "បន្តវេនពី"
{
    public string ExpiryDate;
}

សំណួរ!
